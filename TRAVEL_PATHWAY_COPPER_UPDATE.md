# SENCHI GLOBAL LLC — Your Travel Pathway copper update

The **Your Travel Pathway** section on the homepage now uses **#BA6316** as its background. The heading and description are white, with mint (**#C4FFDD**) highlights. The visa selector keeps its white cards and deep-teal (**#007474**) content; the selected tab is copper. This helps readability and keeps the copper limited to this section.

## How to run locally

Open this folder in VS Code and run `npm start` (or launch `index.html` with Live Server). Scroll down to **Your Travel Pathway**, choose a Tourist, Student, or Work Visa tab, and check at both phone and desktop sizes.

## How to publish to GitHub Pages

Upload the **contents** of this extracted folder to your repository root, not the ZIP. Keep `index.html` directly at the top level, and preserve any personal updates in `js/site-config.js` or custom images. Commit to `main`; wait for GitHub Pages Actions to report a successful deployment and refresh the public website.
