# SENCHI GLOBAL LLC — Subtle copper accents

The main brand colors remain **#007474**, **#C4FFDD**, and **#FFFFFF**. The new accent **#BA6316** is used only in small details, not entire sections.

## Where copper appears

- Hero's tiny dot and decorative rule beside the introductory eyebrow
- Small sparkle icons on selected section headings
- Thin outline on service photo labels and service arrow circles
- Outline and icon on the visa pathway badge
- Step numbers in the four-step process
- Outline of FAQ toggle controls
- Thin borders around visa detail photos and document note sidebars

## Run locally

Extract the ZIP so `index.html` is at the top level, open the folder in VS Code and use Live Server; or run `npm start` and visit `http://localhost:4173`.

## Deploy to GitHub Pages

Upload/commit the contents of this ZIP to your existing GitHub Pages repository on `main`. Keep `index.html` in the repo root. The most important new file is `css/warm-accent.css`; the five HTML pages reference it with a version query string to avoid stale cached CSS. Check GitHub Actions for a successful Pages deployment. Refresh with Ctrl+Shift+R.

**Preserve your own customized `js/site-config.js`** before replacing the project, and preserve any logo changes you made after the previous ZIP.
