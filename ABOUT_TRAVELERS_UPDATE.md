- Fully responsive: the image appears on the left on desktop and stacks on mobile.

## VS Code

Extract this ZIP and open the project folder. Run `npm start`, then visit `http://localhost:4173`. Or open `index.html` using Live Server.

## GitHub Pages

Upload all files *inside* the extracted project folder to the root of the repository, replacing the older files. Commit to `main` and check Actions for deployment success. Do not put the entire extracted folder inside another repository subfolder; `index.html` must remain at repository root.

Preserve the `js/site-config.js` values from your current site if you have updated your business email, telephone, or social links since the previous release.
