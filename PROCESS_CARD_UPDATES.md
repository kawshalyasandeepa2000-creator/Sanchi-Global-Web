# SENCHI GLOBAL LLC — Enhanced four-step process

The homepage `#process` section now has:

1. **Tell us your goal** — identify the visa interest, destination and timeline.
2. **Understand the route** — review the visa type, official requirements and checklist.
3. **Prepare with care** — organize forms, evidence and any applicable appointments.
4. **Move forward informed** — follow official submission instructions, monitor requests, and prepare for decisions.

Each card has a new animated inline SVG icon, three detailed points and a clear takeaway. Animations pause for users who prefer reduced motion. The design keeps teal (`#007474`), mint (`#C4FFDD`), white (`#FFFFFF`), and restrained copper (`#BA6316`).

## How to run

Extract the complete ZIP, open the folder in VS Code, and run `npm start` (or open `index.html` with the Live Server extension). To publish on GitHub Pages, upload **all files and folders inside the extracted folder** to the repository root, commit, and deploy the `main` branch from `/(root)`. Retain your current `js/site-config.js` if you have customized contact details.

The external `js/site.js` and built-in HTML fallback script both contain the same new process markup.
